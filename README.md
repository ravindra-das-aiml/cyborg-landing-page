# AUGMENTA — Cyborg-Themed Landing Page

A responsive landing page concept for a fictional neural augmentation brand, built for the "Cyborg-Themed Landing Page Development" task.

## Concept
The page is built around the human/machine duality at the heart of the cyborg theme:
- **Copper accent** — represents the human, organic side.
- **Cyan accent** — represents the machine, synthetic side.
- A vertical "neural spine" runs down the page, connecting each feature module like nodes on a nervous system — a literal and visual metaphor for the theme.

## Sections
- Hero with live "vitals" readout
- Three feature modules (Reflex Core, Memory Weave, BioShield) alternating along the spine
- Stats/metrics band
- Testimonial quote
- Waitlist call-to-action

## Tech
- Plain HTML + CSS (no framework)
- Fully responsive — spine layout collapses to a single-column rail on mobile
- Accessible: visible keyboard focus states, reduced-motion support
- Fonts: Unbounded (display), Manrope (body) via Google Fonts
